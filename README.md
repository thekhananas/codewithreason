# SocraGate

An execution-grounded Socratic coding tutor with a FastAPI/LangGraph backend and a Next.js workspace.

The application lives in [`code-with-reason/`](code-with-reason/). See its [README](code-with-reason/README.md) for setup, architecture, API contracts, verification, and execution limits.

After installing the documented dependencies:

```bash
cd code-with-reason
./scripts/dev.sh
```
